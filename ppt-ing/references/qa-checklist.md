# 交付前清单

按顺序过，任一项不通过就回去改，不要往下走。

## 一、结构

- [ ] 页角色齐全：12 页以上必须有 `cover / index / section / content / summary / closing`
- [ ] 15 页以上至少 8 个不同 `layout_variant_id`，且差在构图几何不是换图换色
- [ ] 同一版式家族不连续超过 3 页；相同构图不连续超过 2 页
- [ ] 卡片式页面 ≤35%；重复标题几何 ≤40%

## 二、字体

- [ ] 每个文本框都写了 `a:ea`，中文没有回落
- [ ] 实际使用的字体在本机存在（看图确认，不能只信代码）
- [ ] 六角色都有实例，字号落在规定区间
- [ ] Caption 有字距；正文没有过度加字距
- [ ] 中文没有方块、没有半角/全角混排、没有孤字成行

## 三、几何

- [ ] 所有元素在画布内，无越界
- [ ] 左右安全边距一致（默认 0.95in）
- [ ] 正文行宽 ≤4.3in；没有一行超过 28 个汉字
- [ ] 文字没有压在图片主体或深色区域上导致不可读
- [ ] 基线对齐：同一行的标题/编号/元信息落在同一基线上

## 四、视觉

- [ ] 强调色不超过 3 处
- [ ] 没有空线、空环、纯装饰框、默认阴影、发光
- [ ] 每个形状都能回答「它在这里干什么」
- [ ] 每页只有一个主效果 + 最多一个辅助效果
- [ ] 页面不是「标题左 + 图右」的默认躺平

## 五、可编辑性

- [ ] 文字全是原生文本，不是图片
- [ ] 图表/剖面/图示是原生形状组合，不是整页截图
- [ ] 图片是独立素材，可单独替换
- [ ] 打开 pptx 后能直接双击改字

## 六、渲染

- [ ] 用 `export_png.ps1` 真实渲染过，不是只跑代码
- [ ] 逐页看过图，不是抽查
- [ ] 预览图来自**最终交付版本**（改完没重新渲染等于没查）
- [ ] 动效若已写：时间线顺序、自动换页、静态兜底都验证过
- [ ] 没装 PowerPoint 就**不许**声称通过渲染 QA

## 七、事实

- [ ] 所有数字有来源或明确标注为虚构/示意
- [ ] 没有用生成图冒充实景、真实人物、真实业绩
- [ ] 甲方名称、项目名、人名核对过（**尤其警惕撞上真实机构**）
- [ ] 引用他人作品/图像有授权或标注
